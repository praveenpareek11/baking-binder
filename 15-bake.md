# 15. Bake

**Program:** 15 — Bake
**Loaf size:** Not selectable
**Crust color:** Used here as a **temperature selector**, not a color setting
**Type:** Utility — extra baking only (no knead, no rest, no rise)

---

## About this program

Additional baking for breads that are **too light or not fully baked through**. Also used for the empty-burn-in step before first use.

There is **no kneading or rest** — the program just bakes.

---

## Temperature settings (via CRUST COLOR button)

| Crust setting | Temperature |
| --- | --- |
| Light | 100°C |
| **Medium (default)** | **150°C** |
| Dark | 200°C |

---

## When to use

- **An under-baked loaf** from another program — return it to the pan and run Bake for an extra 10–20 minutes at 150°C or 200°C.
- **Cakes that aren't set in the center** — run an extra 5–10 minutes at 150°C.
- **First-use burn-in** — run empty for 10 minutes (medium / 150°C) to drive off any factory residues. Some smoke/odor is normal on the first or second use.
- **Reheating bread** — light setting (100°C) for 5–10 minutes refreshes a day-old loaf.
- **Toasting nuts or seeds** — light setting, watch closely, stir occasionally.

---

## Tweak notes

- Default time is preset for the program — duration cannot typically be customized beyond letting it run to completion.
- For more control, you can press START/STOP at 3 seconds to end Bake early once the loaf reaches the desired doneness.
- **Never run Bake empty** except for the first-use burn-in — it stresses the heating element.
